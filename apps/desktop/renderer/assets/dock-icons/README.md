# Dock 图标资源

程序坞统一使用 `la-capitaine/` 中的 SVG 图标；新增或未匹配的 App 使用
`applications-other.svg` 通用图标，不再回退到旧图标主题。La Capitaine 图标主题来自
https://github.com/keeferrourke/la-capitaine-icon-theme，图标美术以 GPLv3
授权分发；本目录同时保留上游 `LICENSE`、`COPYING` 与 `Credits.md`。

| 文件名 | 图标 |
|---|---|
| workbench.svg | 工作台（workspace） |
| chat.svg | 对话 |
| research.svg | 研究 |
| literature.svg | 文献工作台 |
| data.svg | 数据 |
| artifacts.svg | 产物（Stacks） |
| settings.svg | 设置 |
| trash.svg | 废纸篓 |
| applications-other.svg | 未匹配 App 的通用图标 |

SVG 资源按原始尺寸缩放，适合高分辨率屏幕。

## 关于 Smartisan 拟物图标

SmartisanTech 官方 GitHub 开源的是内核（GPL-2.0，GPL 合规义务）与
Android 平台代码（Apache-2.0），**不包含图标美术资产**；网络上流传的
图标包均为无许可证转载。若你通过合法途径自行获得图标文件（例如从自己
的设备提取作个人使用），放入本目录即可生效；请自行确认使用范围，不要
将有版权的图标提交进公开仓库。
