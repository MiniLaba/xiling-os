# 汐语灵境设计系统

> 汐灵 OS 界面设计的唯一参照规范。任何 UI/交互修改必须先对照本文；
> 令牌的代码事实源是 `packages/ui-tokens/src/index.ts`（生成 `apps/web/src/styles/tokens.css`，由测试锁定同步）。
>
> - 状态：有效
> - 建立：2026-08-31
> - 适用范围：apps/web 全部视图、后续新增界面、文档中的 UI 描述

## 1. 设计哲学：汐语灵境

产品名「汐语灵境」由两部分构成，它们是全部界面决策的根：

- **汐语 = 潮汐的语言**。界面有潮汐的呼吸节奏：运行态如潮汐般低频脉动，状态切换如潮水进退般平滑（慢进缓出），布局留白如潮间带的呼吸空间。拒绝突变、弹跳与闪烁。
- **灵境 = 钱学森提出的「灵境」系统**（virtual reality 的中文命名）。界面本身消隐，研究对象（问题、证据、主张、推演、产物）才是空间中的实体：低铬、直接操纵、沉浸。装饰必须让位于对象。

由此导出四条设计原则，任何新能力必须同时回答：

1. **界面退后，对象上前**。每一个像素服务于证据链；与科研对象无关的装饰一律删除。空状态、加载态也是信息，不是插图。
2. **潮汐节奏，拒绝突变**。所有过渡使用潮汐缓动 `cubic-bezier(0.22, 0.68, 0.31, 0.99)`；时长只用三拍：180ms（快）、320ms（常）、560ms（慢）；运行态用 2600ms 呼吸脉动。禁止 spring 弹跳、禁止彩虹加载条。
3. **位置即语义，连线即证据**。空间坐标和有向带标签的连线是用户的推理结构：系统永不自动重排用户摆好的布局；「整理」只整理无位置节点，且总提供「还原布局」。
4. **渐进披露，大图可读**。缩小时先隐去文字保留结构，聚焦时按邻域深度展开；同一视图以不同信息密度承载宏观与微观。

竞品参照（实现时对照，不抄袭）：flowith 的「对话即画布」分支自治与可视化上下文；Obsidian Canvas/Graph 的位置语义、渐进披露与邻居深度聚焦；Linear 的动量优先与键盘可达；Are.na 的证据块多归属。

## 2. 主题

两套主题，**跟随系统** `prefers-color-scheme`，并允许用户在“设置 → 外观与主题”中手动覆盖（localStorage 持久化，`data-theme` 属性）。工作区侧栏左下角只保留单一设置入口，不提供会隐藏当前选择含义的循环主题按钮：

| 主题 | data-theme | 定位 |
|---|---|---|
| 灵境 | `lingjing` | 深色沉浸：近黑蓝空间、汐青强调、证据金点睛，长时间研究默认 |
| 破晓 | `poxiao` | 浅色研究：纸感明亮、汐蓝强调，学术阅读与明亮环境 |

规则：
- 底色禁用纯黑 `#000`（眩光与拖影）。
- 任何颜色只通过 `--xl-*` 变量引用；禁止十六进制字面量、禁止第三套 accent。
- 图标与图片在两套主题下分别验收；语义色（立场/关系/实体类型）两主题同构但亮度分别校准。
- ADR 0042 锁定的文献工作台、项目管理和 Wiki 为固定浅色的历史兼容工作区，不作为新页面的设计系统范例；其 CSS 必须保持工作区隔离。

## 3. 设计令牌

完整定义见 `packages/ui-tokens/src/index.ts`，CSS 变量全表见 `apps/web/src/styles/tokens.css`。核心锚点：

- **色彩角色**：`--xl-bg/bg-secondary/surface/elevated/hover`（五层空间深度）、`--xl-text/muted/faint`（三级文字，muted/faint 已按 AA 反推勿再调暗）、`--xl-accent/accent-strong/on-accent/accent-soft`（汐青/汐蓝一族）、`--xl-evidence/evidence-soft`（证据金）、`--xl-success/warning/danger/info`、`--xl-stance-*`（立场四色）、`--xl-rel-*`（16 种关系色）、`--xl-entity-*`（19 种实体类型色）。
- **字号阶**（任何 UI 文字 ≥11px）：caption 11 / small 12 / control 13 / body 14 / lead 15 / section 17 / title 21 / page 28。
- **行高**：tight 1.3 / ui 1.45 / body 1.65 / cjk 1.75（中文正文）。
- **字体栈**：UI=`PingFang SC, MiSans, HarmonyOS Sans SC, Microsoft YaHei, Noto Sans SC…`；西文数字=Inter/SF/Segoe 族并启用 `font-variant-numeric: tabular-nums`；等宽=`SF Mono, JetBrains Mono, Fira Code…`。
- **间距**：4px 网格（`--xl-space-1`…`--xl-space-16`）。
- **圆角**：sm 6 / md 10 / lg 14 / xl 20 / full 999。
- **阴影**：sm/md/lg 两主题各一套（深色更深、浅色更软）。
- **层级**：sticky 10 / overlay 100 / palette 200 / modal 300 / toast 400。
- **动效**：见 §1 原则 2；`xl-tide-breathe`（运行态呼吸）与 `xl-tide-rise`（入场潮涌）两个全局 keyframes。

## 4. 术语表

UI 文案必须使用下表术语，新增概念先登记再用：

| 概念 | 汐灵术语 | 说明 |
|---|---|---|
| Chat / Run Graph | 对话 / 运行图 | Chat 内「对话 ⇄ 运行图」切换 |
| Scientific Canvas | 科研画布 | 五视图：总览 / 文献 / 证据 / 溯源 / 产物 |
| Agent Run | 推演 | 状态文案：推演中 / 已完成 / 已取消 / 已失败 / 挂起 |
| Review | 审议 | Approval=审批，Review=审议，两者不混用 |
| Evidence / Claim | 证据 / 主张 | 立场：支持 / 反驳 / 限定 / 证据不足 |
| Artifact | 产物 | 溯源=Provenance；工作流完成态称「沉淀」 |
| edge / relation | 连线 | 有向、带标签、可着色 |
| follow-up / quote | 沿节点继续 / 组合引用 | 运行图两种节点交互模式 |
| Attention | 需要关注 | 审批、失败、证据缺口与提案的聚合视图 |
| 布局操作 | 整理 / 还原布局 | 「整理」仅建议式重排无位置节点；「还原布局」一键回到自动布局 |
| Skill / MCP | 技能 / MCP 服务 | 设置页分组：智能体 / 服务连接 |
| 工作区 | 工作区 | Workspace 的中文叫法 |

中文排版规范（全站强制）：
- 文案遵循 pangu 规则：中文与西文、中文与数字之间加空格；数字与单位之间加空格；百分比与度数不加（撰写规范，不做运行时 DOM 改写——那与 React 渲染冲突）。
- 中文句子用全角标点；数字用半角；不重复标点。
- 专名大小写准确（GitHub、Docker、NetCDF）。
- `lang="zh-CN"` 保留；正文 CJK 行高 1.75。

## 5. 布局规范

- **应用壳**：两栏骨架（侧边导航展开 220px、折叠 72px / 主工作区）。位置沿用 `27ebdf7` 的稳定信息架构，外观只使用当前设计令牌与组件；设置页独占全宽。
- **Chat 上下文面板**：运行图通过 Chat 内“对话 / 运行图”切换；Artifact Viewer 只在 Chat 内按需打开，≥1040px 可停靠并调宽，窄屏使用抽屉，也可放大为全工作区。应用壳不得再增加常驻第三栏。
- **五个工作面**：对话、科研画布、项目、Wiki、文献工作台 + 需要关注与设置。导航按「科研工作台 / 科研知识库」两组组织，术语见 §4。
- **命令面板**：Ctrl/Cmd+K，方向键导航，焦点圈禁，分组展示，Esc 关闭并归还焦点。
- **空/加载/错误态**：统一使用 EmptyState / Skeleton / Toast 基元；禁止纯文本「正在…」与 `window.confirm`。

## 6. 组件规范

基元组件位于 `apps/web/src/components/ui/`：Button、IconButton、Badge、Card、Dialog、Toast、EmptyState、Skeleton、Spinner、Tooltip、Select。规则：

- **Dialog**：portal 渲染、焦点圈禁、Esc 关闭、关闭后焦点归还触发元素、`aria-modal`。
- **Toast**：右上队列、三拍自动消失、行动可撤销优先于确认框。
- **按钮**：主按钮用 `accent-strong` 底 + `on-accent` 字；危险操作用 `--xl-danger`；图标按钮必须有 `aria-label`。
- **图标**：统一 lucide-react，stroke 1.5，默认 18px；禁止 Unicode 符号当图标（⌁◎✓↑■◆ 等）。
- **Badge**：语义色仅来自令牌（立场/状态/类型），禁止临时色。

## 7. 两个核心视图的交互规范

### 7.1 运行图（Chat 内，参考 flowith）

- 低密对话画布：每轮只呈现「研究指令」与「关键回答」两种卡片（提问卡=汐青边、回答卡=灵境边、子智能体卡=紫韵边）；模型/工具/用量等执行细节折叠为 `hiddenDetailCount` 徽标，点击**就地展开**为细节链。
- 交互模式：「沿节点继续」「组合引用」（锁定语义）；失败节点提供「重新推演」一等操作；delegation 子任务卡可下钻子会话。
- 导航：MiniMap、搜索定位、滚轮缩放（Cmd/Ctrl+滚轮）、fitView；坐标不持久化（DESIGN 宪法），拖拽仅改变当前视图，重新加载后回自动布局并在界面明示。
- 连线：answer/follow-up/delegation 三类，带中文标签、闭合箭头与图例；hover 高亮相邻链。
- 实时性：推演中的卡片接入事件流自动刷新，潮汐呼吸脉动标识；支持按时间回放推演过程（潮汐叙事）。

### 7.2 科研画布（参考 Obsidian Canvas / Graph view）

- 布局：dagre 分层（交叉最小化）；已有持久化位置的节点永不重排；「整理」只整理无位置节点；「还原布局」一键复位。
- 渐进披露：缩放低于阈值时节点退化为类型色点（文字淡出），节点尺寸按引用数映射。
- 连线：16 种关系全部进入可筛选图例；连线可选中查看关系详情；邻居聚焦用深度滑杆（1/2 跳）。
- 搜索：多结果列表 + 全部命中高亮 + 逐个定位。
- 节点卡：类型色 + lucide 图标 + 立场色带；详情面板提供等价文本视图。
- 分组：总览视图以分组框呈现「问题区 / 证据区 / 产物区」（纯视觉容器，不写科研事实）。

## 8. 无障碍验收线

每条 UI 修改必须过线（写入 human-factors 检查与人工走查）：

- 正文对比度 ≥ 4.5:1（AA）；大号文字 ≥ 3:1；连线、控件边框、聚焦指示器等非文本 ≥ 3:1。
- 聚焦环 2px 双色（accent + 底对比色），全站 `:focus-visible` 一致。
- 图谱类视图必须提供等价文本视图（列表/详情面板文本）。
- `prefers-reduced-motion` 全局生效（tokens.css 内置）。
- 无 <11px 文字；色彩语义不得单通道（状态必须同时有形状/文字线索）。
- 模态焦点圈禁与归还；命令面板可全键盘操作。

## 9. 局部调整辅助工具

内置开发者工具（`apps/web/src/devtools/`）：按 **Ctrl/⌘ + ⇧ + D** 或右下角画笔按钮唤起。

- 「选择元素」后点选页面任意元素，可即时调整字号（≥11px 钳制）、padding/margin/圆角、文字与背景颜色（色板来自当前主题令牌，导出时自动反向映射为 `var(--xl-*)`）。
- 「文字」页可对纯文本节点原地改文案做本机预览。
- 所有改动存于 localStorage，仅本机预览；「导出」会生成 CSS 规则并标注应落到的样式文件路径（类名前缀 → 文件映射见 `devtools/tweaks.ts`）。正式修改仍须把导出规则手工落到对应文件，然后在工具里「重置」。

## 10. 走查清单（每次 UI 变更）

1. 只用了 `--xl-*` 变量与令牌导出，无十六进制字面量、无第三套 accent。
2. 无 <11px 文字；中英文/数字间距符合 §4 规范。
3. 过渡只用三拍时长与潮汐缓动；无弹跳闪烁。
4. 深色/浅色两套主题截图核对，对比度过线。
5. 空态/加载/错误/Toast 使用基元组件。
6. human-factors 检查与 ui-dom-smoke 通过；pnpm check 全绿。
