# 五视图低保真交互说明

## 全局框架

- 左侧主导航：研究项目、Chat、科研画布、项目管理、Wiki、文献图。
- 顶部项目上下文：当前项目、当前研究问题、运行环境、上下文构成/缓存复用/费用状态。
- 右侧检查器：当前选中消息、节点、任务、Wiki 或论文的来源与操作。
- 所有高风险动作使用同一种审批抽屉，展示资源、网络、预计成本和可撤销性。

## Chat

- 中央时间线展示消息、工具、审批和 Artifact，而非只显示纯文本。
- 输入区可选择显式上下文：Wiki 页面、论文、数据集、画布节点。
- 每个结果提供“固定到画布”“写入 Wiki 草稿”“创建任务”“保存证据”。
- 当前上下文来自哪些分支、引用和胶囊，以及缓存复用与激活能力，始终可见但不抢占主内容。

## 科研画布

- 画布是空间化的科研对话与 Context Playground，而不是让用户设计执行 DAG。
- 每条用户输入、AI 回答、论文、数据、自由笔记、工具结果、Recipe 步骤和 Artifact 都是可移动节点。
- Follow-up 模式：点击一个节点作为锚点，在其下方继续对话并生成新分支；上下文来自该节点的祖先链。
- Quote 模式：选择多个任意节点作为 Composer 引用，跨分支比较、综合或形成新假设。
- 支持同一提示并行生成 1/2/4 个分支，默认 1；每个分支可使用不同模型或方法。
- Agent 执行时动态铺开 Recipe、检索、代码、图表和检查点；用户可暂停、纠偏或从检查点向后重建。
- 自由节点可用于假设、评论、待验证问题和手工素材；支持画布搜索、框选、分组和自动整理。
- 新回答、新分支和新 Artifact 直接加入画布；覆盖既有内容或删除节点仍通过 Patch 预览。
- 点击节点可在右侧展开完整内容与 provenance，画布卡片只保留紧凑摘要。

## 项目管理

- 首页突出研究问题、下一里程碑、正在运行实验、阻塞任务和最新 Artifact。
- 提供精简列表/看板，不复刻完整企业项目管理系统。
- Experiment 卡片直接关联假设、输入数据、Run、结果和 Reviewer 结论。

## Wiki

- Markdown-first，左侧页面树，中间 Milkdown 编辑器，右侧双向链接/引用/版本。
- Agent 建议以差异形式展示；接受后产生新 Revision。
- 图表和地图嵌入只引用 Artifact，不复制文件。

## 文献图

- 左侧搜索/阅读列表，中间 Cytoscape 图，右侧论文详情与证据操作。
- 节点大小表示引用量，颜色表示年份；图例明确关系类型。
- 支持 Prior Works、Derivative Works、相似工作和本项目已读/已引用状态。
- 默认 40 节点，扩展前提示 API 成本、上下文变化和预计等待时间。

## Windows 状态

- 设置页显示原生 Host、Docker 沙箱、数据位置和剩余空间。
- 从 Windows 导入时解释“复制到科研工作区”的原因和预计空间。
- 路径或 OneDrive 问题提供修复建议，不直接修改系统配置。
