# Desktop V2 实施路线（已被取代）

> 本文件只保留桌面壳阶段的历史记录。当前产品与交付路线见
> [`../ai-native-os/PRODUCT_SPEC.md`](../ai-native-os/PRODUCT_SPEC.md) 和
> [`../ai-native-os/DELIVERY_PLAN.md`](../ai-native-os/DELIVERY_PLAN.md)。不得继续按本页 S0–S7 推进产品功能。

本路线替代旧版 Gate 编号和互相冲突的 D4/D5 描述。每一阶段都必须保持通用 OS 定位、单窗口内部多窗口、真实目录、按需资源与原生跨平台。

## S0 — 产品隔离与防偏离（已完成）

- 机器可读产品清单、仓库开发规则和边界检查。
- 旧版退出活动 pnpm 工作区；新版禁止导入旧包。
- 通用系统应用使用领域中立 ID，科研应用通过插件进入。

验收证据：`pnpm boundary`；根工作区只发现 10 个新版项目；任务中心已由 `system.research` 更名为 `system.tasks`；旧源码不参与新版依赖解析。

## S1 — 桌面与窗口系统完成（下一阶段）

- 文档型多实例窗口、窗口菜单、焦点环和崩溃恢复提示。
- 桌面/程序坞/窗口键盘操作与屏幕阅读器路径。
- PDF 与科研文件查看器按需分块；长目录 DOM 虚拟化。

## S2 — Agent 原生应用平台

- 版本化 App Manifest、实例生命周期和 app-to-app Intent。
- 应用只获得声明且授权的资源句柄；后台应用可挂起、恢复、卸载。
- 第三方可执行入口继续关闭，先完成声明式应用 SDK 与可信 UI。

## S3 — Main Agent 纵向闭环

- 选择性保留 Pi 的工具循环、流式事件、取消、Session Tree 与 Compaction。
- 目标 → Task → App Intent/Tool → Artifact → 可恢复结果。
- Chat 是控制入口；任务中心是状态视图；运行细节不冒充科研事实。

## S4 — Skill、MCP 与动态 Agent

- 常驻轻量索引，命中后才加载 Skill 正文和 MCP schema。
- 子智能体默认上下文隔离，只通过显式 Task/Artifact/Handoff 协作。
- 每个宿主接入统一权限、取消、资源和空闲回收。

## S5 — 原生安全执行与跨平台

- macOS、Windows、Linux 分别实现系统级沙箱适配器。
- 默认断网、文件白名单、CPU/内存/时限、终止和逃逸测试。
- 通过前不执行模型生成代码，不以普通子进程冒充沙箱。

## S6 — 科研应用生态

- 文献、证据、数据、计算、审查、复现作为可安装通用科研包。
- 海洋科学作为领域扩展包，不进入 OS Kernel。
- Research Graph 是科研应用的可重建查询投影，不是第二事实库。

## S7 — 发布

- 安装、签名、自动更新、备份恢复、SBOM 与许可证。
- 三平台真机、低资源设备和黄金任务验收。

任何阶段禁止用示例数据、按钮或界面占位宣称能力完成。
