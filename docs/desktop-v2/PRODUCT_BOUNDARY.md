# Desktop V2 产品边界（桌面宿主历史边界）

> 当前唯一产品定义已经迁移到 [`../ai-native-os/PRODUCT_SPEC.md`](../ai-native-os/PRODUCT_SPEC.md)。
> 本页仅说明冻结旧 Web 产品与当前原生宿主的代码隔离，不再定义产品交互模型。

Desktop V2 是当前唯一活动产品：运行在 macOS、原生 Windows 和 Linux 上的 AI 原生虚拟操作系统。科研只是首批可安装应用方向，不是桌面、任务、Agent、文件或权限内核的命名空间。

## 与旧版的隔离

- 旧版完整历史由 Git 标签 `v1-legacy-freeze` 和分支 `codex/legacy-v1` 保存。
- 当前树中的旧源码只用于人工查阅和经过评审的单向移植，不参与 pnpm 工作区、构建、测试或运行。
- 新版不得 import 旧包，不双写旧数据库，不复用旧网页组合根，也不以旧页面“看起来已有”作为功能完成证据。
- 可复用的是稳定协议、算法和测试思想；移植后代码必须进入 V2 白名单目录并遵循 V2 权限、生命周期和测试边界。

机器可读边界位于根目录 `xiling.product.json`，`pnpm boundary` 是强制门禁。

## 判断一个需求属于哪一层

| 问题 | 归属 |
| --- | --- |
| 桌面、窗口、文件、应用安装、权限、任务调度、Agent 生命周期 | OS 核心 |
| 模型循环、流式事件、工具调用、会话树、压缩 | Pi Runtime Adapter |
| Skill/MCP 搜索、描述、按需激活 | 隔离能力宿主 |
| 文献、证据、实验、科研图谱、海洋数据 | 科研应用/插件 |
| 画布坐标、筛选、窗口布局 | UI 投影，不是科研事实 |

若一个新功能不能明确归入以上一层，先修改本文件和 ADR，再写代码。
