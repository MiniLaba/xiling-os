## 不可偏离的契约

- User → App、Main → App、App → App 使用同一调用服务及数据源。
- App Package 是可升级定义，App Instance 绑定持久 Agent；Activation 是可释放执行实例；Session 是连续工作边界；Task 是交付边界。
- 固定 App UI 与系统生成 UI 并存。设置、任务监视器可为系统界面，不强制创建无用 Agent。
- Runtime 可替换。DSH/Cordis 的支持情况必须根据实际版本验证，不以接口声明代替实现。
- 不增加 Docker/WSL 依赖；不启用未经隔离验证的任意应用代码执行。
- 模拟器仅用于测试。没有真实运行能力必须失败，不能报告交付成功。
- 不复制全部会话或记忆。权限在执行前检查，沿调用链衰减。
- 科研只是领域应用；保留现有桌面、文件网关与内部多窗口，不再重做外壳。

## 产品扩展及先决条件

1. **拖产物给 App**（P3 后）：类型匹配、操作预览、授权后发起任务；传引用而非隐式共享工作区。
2. **联合工作桌**（P4）：汇总产物、待决策与状态；不把运行事件全量画成图。
3. **分支试做**（P4）：新 Task/Artifact 版本比较；不宣称能撤销已经发生的付款、发送等外部行为。
4. **可纠正记忆**（P5）：展示来源、作用域与删除入口；项目偏好不自动变成全局偏好。
5. **保存为个人 App**（P6）：保存经确认的输入输出、能力和界面定义，不复制完整历史或凭据；新实例默认私有记忆。

每项扩展均需直接使用、委托使用、拒绝授权、重启恢复四类验收。不预先开发商店交易、远程自治或无人值守外部副作用。
