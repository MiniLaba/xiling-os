# 汐灵：AI 原生虚拟操作系统产品规格

状态：当前唯一产品定义
目标依据：用户最新《AI 原生虚拟操作系统》开发目标（2026-09-05）
生效日期：2026-09-05

## 最新目标优先约定

App = Persistent Agent。用户直接打开 App 与委托 Main Agent 调用 App 是同等入口；App 也可调用获授权的其他 App。三个入口共用应用服务、产物和权限模型。固定 App UI 与系统生成 UI 并存。下文旧版“临时应用”“目标优先”表述不再具有排除独立 App 的含义。

实施及验收以 [APP_AGENT_DELIVERY.md](APP_AGENT_DELIVERY.md) 为准。

## 一句话愿景

把“人操作一堆固定软件”，变成“人表达目标，AI 动态组成软件”。

汐灵不是新的 Windows/macOS 内核，也不以仿制传统桌面为产品目标。它运行在现有操作系统之上，管理长期 Agent、一次次 Session、即时 Context、长期 Memory、Workspace、Plugin、Task、Artifact、A2A 协作和 Generative UI。

## 产品公式

```text
AI Native App = Agent + Memory + Plugins + Workspace + Generative UI

用户目标
  → Main Agent 理解意图与边界
  → 创建可恢复 Task
  → 按需发现并加载能力
  → 必要时委托隔离 Agent
  → 通过 A2A 返回最小上下文与 Artifact
  → 仅在比较、选择、授权、审批时生成可信 UI
  → 用户作关键决定
  → Agent 继续执行并交付结果
```

## 核心对象

| 对象 | 回答的问题 | 必须保持的边界 |
| --- | --- | --- |
| Agent | 谁在工作 | 长期身份；不预设职业；能力来自插件装配 |
| Session | 这一次连续工作发生了什么 | 属于单个 Agent；保存轨迹引用，不等于长期记忆 |
| Context | 模型这一刻看见什么 | 每轮编译；只装入当前任务所需材料 |
| Memory | 以后仍应记住什么 | 经选择、可追溯、按 Agent 隔离 |
| Workspace | 工作属于哪个世界 | 文件、环境、权限和共享材料的边界 |
| Plugin | 此刻获得什么能力 | 按需发现和加载；权限先于执行 |
| Task | 系统正在推进什么 | 可调度、等待、委托、取消、恢复 |
| Artifact | 交付了什么 | 版本化、内容寻址、带来源链 |
| A2A | Agent 如何协作 | 只传任务、必要上下文、衰减权限和 Artifact |
| Generative UI | 人现在需要看或决定什么 | 从可信组件注册表选择，不执行模型生成代码 |
| Harness | Agent 如何运行 | 位于适配器边界后；产品语义不由 Harness 定义 |

## 体验原则

1. 直接打开 App 与表达目标是同等入口，不强制用户先找 Main Agent。
2. 用户默认只看结果、当前等待、风险和下一项决定；内部推理与工具轨迹按需诊断。
3. App 可有默认用途与能力，但共享通用 Runtime；安装产生持久身份而非固定职业运行引擎。
4. UI 在任务需要人参与时出现。比较用对比组件，日期用日历，位置用地图，危险动作使用审批面板。
5. App 是可独立使用、可被组合调用的工作单元；文件和窗口提供熟悉的直接操作入口。
6. 多 Agent 默认隔离。协作不是复制完整聊天记录，而是显式交接。
7. Token 节省来自架构上的少加载、晚加载、引用传递和隔离，而不是粗暴截断所有任务。

## 非目标

- 不重写硬件操作系统、驱动或窗口服务器。
- 不以“像 macOS 的桌面皮肤”作为完成标准。
- 不为每种 App 自研固定职业 Runtime。
- 不默认启动多个常驻 Agent。
- 不把完整历史、全部 Skill、全部 MCP schema 或大型 Artifact 塞进上下文。
- 不允许模型生成的任意前端或脚本直接执行。
- 不把科研、办公或任何单一领域概念写进 OS Kernel。

## 当前代码的处理原则

- `apps/desktop` 暂时继续作为原生宿主路径；路径名不代表产品定义。
- 已实现的单窗口内部多窗口、真实文件夹、能力网关、事件存储和惰性资源可保留。
- 已实现的 Agent/Task/Memory/Plugin/A2A/Artifact/可信 UI 只能按本规格重新验收，不能因“已有类名”直接视为完成。
- 文献、数据和科研模块降为可安装领域插件；它们不得决定首页、Agent 类型或内核模型。
