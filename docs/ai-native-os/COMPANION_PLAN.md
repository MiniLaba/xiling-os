# 系统级虚拟伴侣：后续集成计划

更新：2026-09-06。文字伴侣已实现，复用 React 与原创 SVG；通过原生界面提交、显示真实失败状态。AIRI/VRM 保留为候选但未安装，避免第二运行栈。支持同源会话、任务取消、产物预览、显式文件选择、关闭与减少动画。未实现语音或 3D，不宣称 Grok 功能对等。实施决定见 ADR 0053；下文候选计划仅适用于未来增强。

## 产品职责

伴侣是用户可关闭的系统交互入口：表达目标、解释真实任务进度、提示待授权事项、打开对应应用或产物。它不是第二个 Main Agent，也不拥有独立任务库、凭据库或默认可读全系统的记忆库。用户仍可使用文字、应用窗口和任务中心；关闭伴侣不应取消后台任务。

目标路径：伴侣界面 → 现有用户入口 → Main / Session / Task → 同一能力与审批网关。动画层只消费可展示的任务状态，不推测或展示虚构的模型思考。选择哪个 Session、附带哪些文件引用必须可见；切换窗口不自动复制上下文。

## 开源优先与选择边界

| 候选 | 已核查信息 | 拟复用方向 | 集成前仍需验证 |
| --- | --- | --- | --- |
| [AIRI](https://github.com/moeru-ai/airi) | 官方仓库标注 MIT，提供虚拟角色、语音交互与桌面方向 | 优先评估角色表现、语音交互组件；参考状态反馈和生命周期 | 模块可拆性、依赖体积、与 React/Electron 的边界；不得整体引入另一套 Agent/记忆/服务器 |
| [three-vrm](https://github.com/pixiv/three-vrm) | [代码许可证 MIT](https://github.com/pixiv/three-vrm/blob/dev/LICENSE) | 可替换的 VRM 角色渲染层候选，不是智能体框架 | 实际显存/内存、设备兼容、模型资源释放、角色资源授权 |

不复制 Grok 角色或品牌资产。开源代码许可证不等于角色、动作、声音或模型权重许可证；逐项建立来源和允许分发范围。Live2D 若纳入候选，另审 SDK 与模型授权，不假定由 AIRI 的 MIT 覆盖。正式选型时锁定版本和提交，并补充第三方声明；当前未引入这些依赖。

## 必须遵守的接口与资源约束

- 伴侣展示适配器与 Agent Runtime 分离；输入仍进入当前内核的用户提交路径，不允许渲染组件直接调用模型或文件系统。
- 默认文字可用；麦克风需明确授权，先做按住说话。关闭录音必须释放媒体轨道；不默认常听、截屏、读取摄像头或剪贴板。
- 原生音频能力按具体模型和适配器验证，不支持时禁用；独立语音识别/合成只能作为明确标注的可选功能，不冒充模型原生音频。
- 人格只影响表达，不提升权限。情感交互不能催促授权、制造依赖或阻止用户关闭；不凭交谈自动写全局记忆。
- 角色包懒加载；隐藏/最小化暂停动画，禁用后释放 WebGL、音频、监听器。不得新增常驻模型进程或第二个 BrowserWindow。
- 资源指标先实测再设预算：记录关闭、静态、动画、语音四种状态的 RSS、CPU、GPU、启动与响应时间。关闭状态主入口不得加载角色引擎。

## 实施顺序与验收

1. P1 真实任务与取消完成后：接入纯文字伴侣入口；同一 Session 在伴侣和普通界面提交、取消、查看结果一致，避免重复提交。
2. 完成候选隔离样例与许可证审查：角色显示真实的待命/工作/待授权/失败状态；能点击跳转对应任务，不新增事实源。
3. 接入可选语音：测试授权拒绝、录音中断、断网、模型不支持、切换会话和关闭释放。不存在后台偷偷录音。
4. 通过资源与可访问性验收后才默认推荐启用：键盘操作、文字替代、减少动画、持久化开关；重启不自动恢复录音。

单元与冒烟使用固定事件，无真实麦克风/模型依赖；真实语音及三平台资源实测单列，不用模拟结果证明完成。当前下一步仍优先修复 P1 配置与工具闭环，而不是扩充角色外观。
