# ADR 0043：以 Electron 全新实现科研桌面 V2

- 状态：已接受，骨架已实现
- 日期：2026-09-02

## 背景

旧版已经验证了 Pi、科研执行、图谱、项目和知识工作面的主要概念，但浏览器启动、HTTP 中心化组合和固定网页布局不足以支持应用生命周期、后台任务、原生文件、进程隔离与可恢复工作空间。继续在旧壳上渐进修改会让兼容成本支配产品设计。

## 决策

在同一 GitHub 仓库建立 Desktop V2，选择 Electron 作为原生宿主。旧版在标签和维护分支永久冻结；V2 不复制旧源码目录，也不兼容开发期数据。Desktop Main、沙箱 Renderer、Core Utility Process、Execution Provider 和 Plugin/MCP Host 形成不同权限域。Fastify后续降为可选传输适配器。

所有 GitHub 开发继续通过 `codex/*` 分支和 PR，不直接提交主分支。

## 后果

- 可以删除旧页面、组合根和数据模型中的不合理部分。
- 需要重新完成三平台安装、签名、更新、恢复和安全测试。
- Pi Harness 与科研核心必须通过稳定端口移植，不能在桌面壳中重新实现。
- 旧版与新版可以同时运行和独立发布，但不得共享活动数据库。
