# ADR 0049：Harness 启动契约必须显式

日期：2026-09-05。状态：接受。

已安装 dsh-sdk-client 0.1.1-rc.2 的 README 明确：SDK 是客户端库，不提供运行程序发现；调用方指定 command/args，运行组合由目标配置决定。仓库此前猜测的包 bin 和 `--profile sdk` 无已核实依据。

改为显式 XILING_DSH_BIN + JSON XILING_DSH_ARGS；不使用 shell，不自动猜测配置或下载运行程序。缺配置在运行前失败，参数错误不阻止其余桌面功能启动。路径和参数分别传输，保留 Windows 空格与中文路径。

这不是完成真实 Harness 打包：工具、凭据、审批、安全组合及恢复仍待 P1 验收。不得为了通过模型连通性测试而静默换成另一套直接请求循环。

接口替换仍限定 os-runtime。冒烟覆盖缺失程序、非法参数、中文/Windows 路径与参数复制。另修复订阅清理异常仍释放会话锁和回收进程，避免一个错误阻塞后续运行。
