# ADR 0053：原生工具、官方压缩与同源伴侣

日期：2026-09-06。状态：已实现；外部提供商与跨平台发布验收另列。

## 决策

- 保留官方 DSH 循环，以 defineTool 注册单个 xiling_os 操作入口。宿主运行短生命周期的 loopback 工具桥，每次运行独立随机令牌、方法白名单，拒绝浏览器 Origin；关闭运行即撤销桥。
- 所有副作用在 OSKernel 前验证 Agent、Task、Run 的当前归属、安装时动作授权和显式产物引用。Main 的内部产物能力来自其 agent.message 基础身份，不等于任意磁盘权限。App 需单独批准产物、委托和追问动作。
- 工具提供内部 Markdown 产物、分页读取、App 发现与有限深度委托、可信追问表单。无任意 shell、文件路径或网络执行器。调用回执去重不是跨数据库事务的 exactly-once 保证。
- 官方 dsh-token-meter、dsh-compaction-basic 与 dsh-compaction 使用同版本 0.1.1-rc.2。按模型窗口压力自动压缩，保留官方检查点；科研/工作成果由 Artifact 持久化，不以压缩摘要替代事实。
- 新文件输入经系统文件选择器形成 UTF-8 文本快照，再由用户显式加入某次任务。不把整桌面隐式交给 Agent。导出经保存对话框，独占创建、不覆盖既有文件；截断预览不能伪装完整导出。
- 伴侣复用 React 与原创 SVG，无额外 3D 引擎。它共享 Main 会话标识和任务事实源，支持目标、状态、取消、文件引用与结果预览。默认关闭、懒加载、关闭卸载、收起停止刷新/动画，不增加模型进程。
- 复用 AIRI 整套服务会引入第二套状态与资源栈，本批不采用；VRM、声音属于后续可替换表现层，不宣称已经实现。
- 历史 scripted Main 通过设置中的显式迁移按钮启用内置引擎，保留历史和策略。重启中断标记失败，不静默重放外部副作用。

## 验证与限制

通过产品边界、内核构建、桌面类型检查与生产构建；真实 SDK 子进程连接本地协议 fixture，经工具桥生成并持久化必要产物。定向拒绝用例覆盖缺权限、非显式产物、过期 Run。本地 fixture 不是公网真实模型验收。

原生桌面已显示伴侣并真实提交任务，准确暴露旧 scripted 身份；没有把失败伪装成功。最新构建已重启，确认伴侣显示原生文件输入；通过设置按钮将本机 Main 切换至内置 Harness，旧记录保留。设置显示 0 个已连接提供商、0 个模型，未进行公网真实任务验收。自动压缩压力场景、完整委托恢复和三平台资源/发布验证尚未完成。未配置的新凭据不能自行生成。

替换边界：AgentRuntime / RuntimeToolDescriptor 与 OSKernel 独立；Companion 是 renderer 消费者；工具令牌不进入模型提示或业务库。升级需维持这些边界。
