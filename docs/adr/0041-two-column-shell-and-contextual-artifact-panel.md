# ADR 0041：两栏应用壳与 Chat 上下文产物面板

- 状态：已接受并实现
- 日期：2026-09-01

## 背景

`27ebdf7` 之前的界面把应用组织为“侧边导航 + 当前工作区”，运行图与产物只在 Chat 内按需出现。随后合入的三栏布局把第二个 `OutputPanel` 提升到应用壳，导致 Chat 自有的可调产物面板与壳层右栏并存：中间对话宽度受到两套状态控制，非 Chat 页面也承担了不属于自身的信息架构。

与此同时，最新版已经形成新的设计令牌、主题、组件基元、科研图交互、后端架构、原生 Windows 控制面和 Docker 沙箱。这些能力不应因恢复旧布局而回退。

## 决策

1. 版本整合采用“最新版能力事实源 + `27ebdf7` 布局位置基线”，不把旧提交整体覆盖到最新版。
2. 应用壳恢复为两栏：展开侧栏 `220px`、折叠侧栏 `72px`、其余空间全部属于当前工作区；设置页继续独占全宽。
3. 侧栏顺序保持为品牌、项目选择、新建对话、主导航、对话历史、左下角单一设置入口；主题选择归入设置页“外观与主题”，避免侧栏出现孤立的循环切换按钮。
4. 删除应用级 `OutputPanel`。Chat 继续拥有：
   - “对话 / 运行图”切换；
   - 只在有需要时打开的真实 Artifact Viewer；
   - 宽屏停靠、拖动调宽、窄屏抽屉和全屏查看。
5. 科研画布、项目、Wiki、文献工作台与需要关注视图获得完整主工作区，不共享 Chat 的产物栏。
6. 视觉实现只能使用当前 `@xiling/ui-tokens`、模块化样式和 UI 基元；不得恢复旧版硬编码颜色、低于 11px 字号或旧单体 CSS。
7. 本决策不改变 Server、Agent Harness、Research Graph、执行内核、Windows 控制面、沙箱、数据模型或持久化格式。

## 被否决方案

- **回退整个仓库到 `27ebdf7`**：会丢失最新版后端、安全、平台和科研内核能力。
- **保留应用级右栏并隐藏 Chat 内面板**：会让运行图/产物脱离产生它们的 Session 上下文，并让其他视图永久损失横向空间。
- **同时保留两套右栏**：状态、尺寸与关闭行为互相竞争，无法形成稳定的人机模型。

## 后果与验证

- App 只负责全局导航和工作区定位，Chat 自己负责会话相关的运行图与产物。
- 旧版用于约束信息位置，不再作为样式或功能事实源。
- `web-human-factors-check` 必须阻止应用级 `OutputPanel` 回归，并验证两栏壳、可折叠侧栏和 Chat 内 Artifact Viewer。
- 桌面与窄屏均需验证：侧栏折叠、Chat 调宽、Artifact 抽屉/全屏、设置全宽，以及科研画布和文献工作台不被第三栏压缩。
